# Design Workflow

Every meaningful UI change in this portfolio follows the same sequence.

1. Define the page job: reader, purpose, content type, and primary action.
2. Consult the local design skill for layout, type, motion, performance, or accessibility guidance.
3. Reconcile with `DESIGN.md`, which is the current site authority.
4. Implement only in the source path:
   - `data/content.js`
   - `scripts/build.js`
   - `styles/site.css`
   - `scripts/site.js`
   - `scripts/writing.js`
5. Run the build and validation checks.
6. Inspect the generated pages on desktop and mobile.

## Current Direction

The redesign guide in `files 2/pelumi-editorial-redesign-guide.md` supersedes the older obsidian/cyan system. Build toward an editorial, paper-first portfolio where the writing and systems work reinforce each other.
